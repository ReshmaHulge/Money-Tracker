# Money Tracker – Personal Finance Management System

## About the Project
Money Tracker is a web-based application developed using Python and Flask. It helps users manage their income and expenses and understand their spending habits.

## Features
- User Registration and Login
- Add and Manage Income
- Add and Manage Expenses
- Transaction History
- Expense Reports and Analysis
- Excel File Upload and Analysis
- PDF Upload and Analysis
- Category-wise Expense Analysis
- Dark Mode and Light Mode

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Pandas

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/ReshmaHulge/Money-Tracker.git
   ```

2. Open the project folder:
   ```bash
   cd Money-Tracker
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   python app.py
   ```

## Purpose
The purpose of this project is to make income and expense management simple and help users understand their financial activities.
